# Tkinter-password-manager
# 🔐 Password Manager

A desktop application developed using Python and Tkinter to securely manage website credentials with password generation, storage, and search functionality.

## Features
- Generate strong random passwords
- Save credentials in a JSON file
- Search and retrieve saved passwords
- User-friendly GUI built with Tkinter
- Error handling for missing data and files
